Device topology and parameter indexing

integrity_check and spec_conformance_check resolve declared terminal roles through the shared convention helpers. The checks describe the package's supported indexing domains; the same array length can mean different things for different devices. They do not reorder or mutate the case. The implementation and regression evidence are linked to PSK-000002 in knowledge/executable.toml; the scientific claim remains book-owned.

Field coverage

Here, phase order means terminal_map order with the identified neutral removed; bus phase order means terminal_names order with neutral removed. Cyclic coils connect map position k to k+1, wrapping at the end. A two-terminal SINGLE_PHASE load, generator or IBR has one coil in either orientation, whether phase-to-neutral or phase-to-phase.

Absent optional bounds are allowed. Empty generator/IBR/source P/Q or supported current/apparent-power limit arrays retain the native meaning “no authored limits”; a nonempty partial vector is diagnosed. Cost and filter arrays must cover every indexed quantity. No scalar broadcast is invented for capabilities, costs, source references or bus bounds. Filter arrays retain their declared extension indexing contract; this does not assert that the native OPF stamps a physical filter. The scalar b_filter_shunt is not a phase array.

ZIP/exponential shape checks are owned by domain_rules_check; the other field shapes are owned by integrity_check. Applicable coefficient fields retain their previous scalar/length-one allowances. The JSON schema and migration layers may impose additional representation requirements; this change does not expand the external schema. In particular, scalar bus v_min/v_max remain a pre-migration representation rejected at ingest; static validation does not migrate them. vpn_* without an identified neutral is explicitly unassessed. Voltage-reference interpretation and feasibility remain separate from shape validation (see #119).

Roles, permutations and diagnostic evidence

Declared terminal_conventions take precedence over naming guesses or a stale materialized neutral_terminal. Equivalent n, 4 and return labels have the same indexing result. With no declaration, existing inference and W.CONV.TERMINAL_ROLES_INFERRED remain in place.

WYE/FOURLEG phase order follows the map after removing its neutral; the neutral need not be last. Phase permutations and reversed single-phase pairs are valid, although `I.TMAP.PERMUTEDORDERmay still describe their ordering. The older WYE “last terminal must be neutral” diagnostic now checks whether the identified neutral is missing. Existing duplicate-terminal and DELTA-neutral diagnostics remain.THREELEGrejects neutral involvement;FOURLEGrequires an identified neutral return. Explicit earth conductors are outside these device models and receiveE.TMAP.DEVICE_ROLES`, rather than being silently counted as phases.

The data-model conformance arities (W.SPEC.CONFIG_ARITY and W.SPEC.INV_TMAP_ARITY) are unchanged. A native reduced-phase boundary may have correctly sized parameter arrays and still receive that conformance warning. An implicit-reference WYE retains its existing W.INT.WYE_WITHOUT_NEUTRAL warning; no new implicit return is inferred by this work.

W.INT.DIM_MISMATCH includes bus, topology, terminal map and positions, resolved roles, role provenance, indexing domain, allowed lengths, scalar allowance and observed shape. Existing load arity codes carry the same evidence. Overlapping, unclassified or multiple-neutral roles produce W.INT.DEVICE_INDEXING_UNASSESSED with status="indeterminate"; no expected dimension is guessed. Declaration hygiene keeps its existing E.CONV.* / W.CONV.* ownership, and unknown references keep E.INT.* ownership. The new unassessed finding explains why indexing cannot proceed; it is not a second declaration error.

These checks handle malformed device maps and indexed-field shapes without indexing or converting invalid payloads. They are static validation passes, not a guarantee that every analysis or solver entrypoint accepts arbitrary schema-invalid input. No OPF model, parsing behavior, branch/winding endpoint rule (#409), or declaration-list hygiene rule (#410) changes here.
