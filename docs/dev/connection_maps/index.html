Branch and winding connection maps

integrity_check visits each line/switch endpoint, each two-bus transformer endpoint, and every original n_winding.windings[k] entry. It checks raw structures without converting winding voltages, impedances or taps. Unknown bus/terminal references keep E.INT.UNKNOWN_BUS / E.INT.UNKNOWN_TERMINAL; their evidence now identifies the endpoint or original winding index. Invalid objects, missing/non-string bus identifiers, and empty or malformed maps use E.INT.CONNECTION_SHAPE. Invalid entries are never dropped or renumbered.

spec_conformance_check resolves the declared roles using the same helpers as device parameter indexing. It does not repair, reorder, truncate or mutate maps. A valid map does not establish that grounding is adequate or that two models are electrically equivalent.

The role-check domain is distinct, declared phase/neutral conductors. Ambiguous or unclassified roles, malformed declarations, multiple bus neutrals, and earth conductors outside this model produce W.TMAP.CONNECTION_UNASSESSED with an indeterminate reason. Declaration hygiene remains owned by its existing checks. Unknown references and malformed structures are diagnosed by integrity rather than duplicated as role errors. A component with invalid map dimensions is not silently shortened for a position comparison.

Phase labels need not match across a line or switch. Phase subsets, arbitrary phase permutations and a single neutral-to-neutral metallic link remain valid. I.TMAP.CROSS_PHASE_LINE and I.TMAP.PERMUTED_ORDER remain informational. A phase-to-neutral transition at a particular position uses the established E.TMAP.PHASE_TO_NEUTRAL code, with both endpoint records and the bad position. Repeated all-neutral maps retain that historical diagnostic as well as the existing duplicate-terminal code.

Transformers can change phase labels, winding connection, terminal count and neutral accessibility. E.TMAP.WINDING_ROLES identifies violations of the subtype's supported map or coupled-coil rule, never equality of conductor roles across independent windings. An autotransformer is not isolated: its two explicit reference bushings are tied, so a neutral-to-phase transition on that specific shared reference is rejected. Neutral-only grounding shunts remain valid nodal admittances and are not subject to a phase-injection rule. No new ground bond or through-neutral requirement is introduced. The existing galvanic-island voltage reference check remains separate and may diagnose an otherwise valid winding.

Runtime and diagnostic boundaries

The original data-model arity warnings remain, even where native reduced-phase or implicit-reference winding models accept a boundary case. An n-winding WYE without an explicit neutral retains W.SPEC.XFMR_TMAP_ARITY; it is not reclassified as a phase-to-neutral continuity error. Numerical transformer parameters, vector group policy (#268), and mesh compatibility (#176) remain with their owners.

These are static structural/role checks. In particular, the native n-winding solver currently restricts labels to a/b/c/n, regardless of valid declared roles. Equivalent renamed maps receive equivalent static role judgments; this does not expand solver or primitive-admittance label support. This change also does not make every analysis, ingestion or solver entrypoint accept arbitrary malformed input, or add a general earth/PE wire model (#70).

Endpoint evidence includes component identity (on the Finding), subtype, side/winding index, bus, terminal map and positions, resolved roles, role source, observed shape and the violated rule. Composite comparisons include all involved endpoints and explicit counts/positions. Tests check stable codes and detail, JSON round trips, deterministic connection findings, and input non-mutation.
