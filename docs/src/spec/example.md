# A worked network example

The [Notation](notation.md) page defines the sets, topology, connectivity, and
terminal-map machinery abstractly. The worked example builds every one of these sets
from a single four-bus network.

The foundational model is in the [Worked example page of the BMOPF specification](https://distribution-system-opt.github.io/math-and-data-model-specifications/stable/spec/example/). BMOPFTools adds nothing to it; the one difference is notation: this documentation writes the bus set as $\mathcal{B}$ where the specification writes $\mathcal{I}$.
