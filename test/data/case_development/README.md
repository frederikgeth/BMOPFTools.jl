# Case-development teaching feeder

Original synthetic four-wire LV example, authored for these package recipes.
It is not derived from a utility feeder and is not statistically calibrated.
The two customer aggregates have different per-phase loads; the unloaded joint
between them allows a simple series reduction with unchanged device identities.
Impedances, ratings and operating bounds are illustrative study inputs.
