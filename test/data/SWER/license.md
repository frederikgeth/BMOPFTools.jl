# QLD-style SWER test feeder

A synthetic isolated single-wire-earth-return (SWER) feeder authored for
BMOPFTools to exercise SWER parsing, grounding-reactor handling, and the
OPF/OpenDSS power-flow cross-check. It is not derived from utility data.
