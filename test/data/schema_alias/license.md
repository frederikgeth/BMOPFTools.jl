# Schema URI regression fixture

`powerio_archive.json` is a synthetic one-bus case authored for BMOPFTools.
It reproduces the schema identifier emitted by PowerIO 0.11.3; no utility or
benchmark network data was copied. Attribution: BMOPFTools contributors.
